--- PÁGINA 18 ---
Prompt Engineering vs Fine-Tuning
Prompt Engineering
• Não necessita de dados para 
começar;
• Menor custo inicial;
• Não necessita de conhecimento 
técnico;
• Conexão com os dados via RAG.
• Muito menos dados de contexto;
• Esquece os dados;
• Alucinações;
• Erros de RAG.
Fine-Tuning
• Capacidade de usar todo dado 
disponível;
• Aprende nova informação;
• Corrige informações erradas;
• Menor custo caso seja utilizado 
modelos menores;
• Também é possível usar RAG.
• Necessita de dados de maior 
qualidade;
• Alto custo computacional 
inicialmente;
• Necessita de conhecimento 
técnico especializado.

LoRA
Low-Rank 
Adaptation)
Benefícios
O que faz?
● Ao invés de modiﬁcar os pesos originais 
do modelo, o LoRA adiciona pequenas 
matrizes treináveis nas camadas internas 
do Transformer;
● Isso permite que o modelo aprenda o que 
é novo (seu tom, seus dados, seu 
contexto) sem esquecer o que já sabe.
● Menor uso de memória;
● Muito mais rápido de treinar;
● Fácil de combinar: pode ter vários LoRAs 
diferentes sobre o mesmo modelo (para 
diferentes clientes, produtos ou tarefas);
● Modelo base permanece intacto;
● Treino em menos de 1% do pesos totais.

--- PÁGINA 25 ---
● Modelos Transformer têm grandes 
matrizes de pesos;
● O LoRA adiciona duas matrizes 
pequenas (A e B) em pontos 
estratégicos (principalmente nas 
camadas de atenção);
● Durante o treinamento, em vez de 
atualizar os pesos originais, ele 
aprende só essas matrizes 
pequenas;
● Na inferência (uso), o modelo usa 
o peso original + o ajuste feito 
pelas matrizes do LoRA.

O que é QLoRA?
QLoRA (Quantized Low-Rank Adaptation) combina LoRA com quantização inteligente 
para permitir o ﬁne-tuning de modelos grandes (até 65B de parâmetros) em GPUs 
modestas (ex: 24GB).
O modelo base é 
reduzido de 16/32 bits 
para 4 bits, 
economizando 
memória.

para aprender os 
ajustes.

--- PÁGINA 34 ---
Por que o ChatGPT é muito melhor que o GPT3?
GPT-3 é um modelo base
• Foi treinado para prever a 
próxima palavra;
• Sabe “um pouco sobre 
tudo”, mas sem entender 
comandos, intenções ou 
alinhamento com usuários.
ChatGPT é GPT-3 + Fine-Tuning + RLHF
• Foi ajustado para entender instruções 
(Instruction Fine-Tuning);
• Depois, foi reﬁnado usando Reinforcement 
Learning with Human Feedback (RLHF), 
aprendendo a dar respostas úteis, 
educadas e seguras;
• Resultado: parece muito mais inteligente, 
alinhado e útil.
