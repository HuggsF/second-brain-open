--- PÁGINA 43 ---
1 - Forward Propagation) Propagação Direta – "Adivinhação Inicial"
Os dados de entrada (ex.: uma imagem, um texto) são "passados" através das 
camadas da rede, da primeira à última. Cada neurônio em cada camada faz um 
pequeno cálculo e passa o resultado para a próxima. Ao final, a rede produz 
uma previsão (ex.: "é um gato", "sentimento positivo").
2 - Loss Calculation) Cálculo da Perda – "Medindo o Erro"
A previsão da rede é comparada com a resposta correta (o "gabarito" dos 
dados de treinamento). A função de perda calcula o quão "errada" foi essa 
previsão. Um número alto significa um erro grande.
Deep Learning
Redes Neurais

--- PÁGINA 44 ---
Deep Learning
Redes Neurais
3 - Backward Propagation) Retropropagação – "Quem Errou Mais?"
O erro calculado é propagado de volta através da rede, da última camada para 
a primeira. O objetivo é determinar o quanto cada "peso" (parâmetro interno) da 
rede contribuiu para o erro total. É como atribuir responsabilidade pelo erro.

--- PÁGINA 45 ---
3 - Backward Propagation) Retropropagação – "Quem Errou Mais?"
O erro calculado é propagado de volta através da rede, da última camada para 
a primeira. O objetivo é determinar o quanto cada "peso" (parâmetro interno) da 
rede contribuiu para o erro total. É como atribuir responsabilidade pelo erro.
4 - Weight Update) Atualização dos Pesos – "Ajustando para Melhorar"
Com base na contribuição de cada peso para o erro, o algoritmo de otimização 
(ex.: SGD, Adam) ajusta ligeiramente esses pesos. A ideia é que, na próxima vez 
que os mesmos dados (ou dados similares) passarem pela rede, a previsão seja 
um pouco melhor (erro menor).

Redes Neurais

--- PÁGINA 50 ---
Overfitting
Bom demais nos treinos, ruim na vida real.
O modelo aprende os dados de treinamento TÃO BEM que memoriza o ruído e os 
detalhes específicos, em vez dos padrões gerais.
Sinais:
● Performance excelente nos dados de treinamento.
● Performance significativamente pior nos dados de validação/teste.
PM Takeaway: um modelo com overfitting não generaliza para novos dados e 
será inútil em produção. É crucial cobrar testes rigorosos em dados não vistos 
para detectar isso.
