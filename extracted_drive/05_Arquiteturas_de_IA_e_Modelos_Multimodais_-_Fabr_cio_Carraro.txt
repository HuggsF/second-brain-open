--- PÁGINA 23 ---
Não se usa redes neurais com multi-layer perceptrons para visão com imagens, pois 
o poder computacional necessário seria enorme.
● Imagem preto e branco de 256256 pixels, a entrada precisaria ter 256² 
neurônios.
● A camada intermediária deve ser proporcional, geralmente até maior. Com 256² 
neurônios, eles se conectariam a todos os da entrada, e teríamos 256^4 pesos 
= 4 bilhões de pesos = 17Gb de memória, apenas para armazenar a rede.
Por isso, em geral, são usadas Redes Neurais Convolucionais CNNs para tratar 
imagens, pois o número de parâmetros não é vinculado ao tamanho da entrada.

--- PÁGINA 31 ---
Arquiteturas de Deep Learning
CNNs: excelentes para dados espaciais (imagens), mas não inerentemente 
sequenciais.
RNNs: boas para sequências, mas com desafios:
● Dependências de Longo Alcance: mesmo LSTMs/GRUs podem ter dificuldade 
com contextos muito longos.
● Processamento Sequencial: dificulta a paralelização do treinamento, tornando-o 
lento para datasets massivos.
 A necessidade: um modelo que pudesse capturar relações complexas em 
sequências (mesmo distantes) e ser treinado de forma mais eficiente em grande 
escala.

Métricas: as mesmas usadas na

produção.
Distribuição dos Dados de Entrada: 
detectar mudanças significativas.
Recursos Computacionais: Uso de 
CPU/GPU, memória, latência.

LIME é como um "intérprete local" que cria um modelo simples ao redor de uma 
única predição complexa.
Explicabilidade
LIME Local Interpretable Model-agnostic Explanations)
● Pega uma única entrada (ex.: uma imagem, uma frase).
● Cria múltiplas variações (perturbações) dessa entrada (ex.: remove palavras, 
esconde partes da imagem).
● Pede para o modelo original fazer predições para todas essas variações.
● Usa essas predições e as variações para treinar um modelo local simples (ex.: 
Regressão Linear, Árvore de Decisão) que se aproxime da predição do modelo 
“caixa pretaˮ somente naquela vizinhança.
● As características mais importantes desse modelo simples local são as que 
explicam a predição original.

Explicabilidade
SHAP SHapley Additive exPlanations
Para uma única predição, calcula a contribuição de cada feature 
comparando a predição com e sem a presença dessa feature, 
considerando todas as combinações possíveis de features (coalizões).
Como Funciona
SHAP é baseado na Teoria dos Jogos e atribui um "valor de contribuição" justo 
para cada feature em uma predição.
