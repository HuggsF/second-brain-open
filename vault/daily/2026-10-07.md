## 🚀 Entregas Realizadas

### 1. Diagnóstico e Causa Raiz (Bug Duplicidade de Etiquetas J&T)
- Identificado que o conector `adapters/bling.js` não extraía o campo `transporte.volumes[0].codigoRastreamento` da API do Bling quando a NF-e já estava emitida.
- O motor `engine.js` chamava a API da transportadora `jtAdapter.generateLabel()` sem consultar o histórico local ou o rastreio prévio do ERP, gerando etiquetas sobressalentes.
- **Documentação gerada:** [[investigacao-duplicidade-etiquetas]] (contendo fluxogramas Mermaid antes/depois, validação manual e critérios de aceite).

### 2. Correção em 3 Camadas & Testes Automatizados
- Implementada proteção em 3 camadas no `engine.js` (linha atual -> histórico da fila -> ERP Bling).
- Otimizada a chamada de `updateTracking` no Bling (dispensada se o código já for idêntico, respeitando o rate limit de 3 req/s do Bling).
- Criada suíte de testes automatizados (`npm test`) em `tests/suite_duplicidade.test.js` cobrindo 4 cenários críticos, executada com **100% de sucesso**.
- Embedada a especificação oficial OpenAPI 3.0 do Bling em [[bling-api-v3-especificacao-pedidos]].

### 3. Governança de Versionamento (Git Workflow)
- Instituída regra de ouro: **proibição estrita de push direto na branch `main`**.
- Criação da branch de trabalho: `fix/duplicidade-etiquetas-jt`.
- Abertura da **Pull Request #1** no repositório GitHub `userTI10/hub-logistico` estruturada com: Causa Raiz, Correção Realizada, Evidências e Diagramas.

### 4. Implantação de Homologação no Servidor (`SRV-API`)
- Criado diretório isolado `/home/ti-kiosk/hub-homolog` coexistindo com a produção.
- Configurado `.env` com `PORT=3001` e banco de dados SQLite independente `DB_PATH=./hub-homolog.db`.
- **Prevenção de custos indevidos:** Forçado `gerar_automatico = 0` na tabela `lojas` da homologação, garantindo que pedidos de teste nunca disparem fretes reais acidentalmente na J&T.
- Suíte de testes `npm test` executada diretamente no servidor Linux com 100% de sucesso.
- Processo adicionado ao PM2 sob o nome `hub-homolog` (ID 1), online e monitorado.
- Proxy reverso Nginx configurado em `/etc/nginx/sites-available/hub-homolog` para o host `hub-hml.touticosmetics.com.br` -> porta 3001.
- **Documentação gerada:** [[implantacao-instancia-homologacao]].

### 5. Pipeline Automatizada de CI/CD (GitHub Actions)
- Criadas branches oficiais `hml` e `dev` no GitHub com push remoto validado.
- Configurado workflow `.github/workflows/deploy-hml.yml` para Homologação.
- Primeira execução da Action concluída com **100% de sucesso** (execução #37678979439), realizando backup do banco SQLite, testes e reload do PM2 no `SRV-API` com zero downtime.
